# Let's Go - Activity Planner

**Swipe, tally, go** - The spontaneous activity planner for groups!

## Features

✨ **Spontaneous Decision Making**: No more endless group chats about what to do
🎲 **Spin to Decide**: Can't choose? Let the wheel decide for you
👥 **Group Voting**: Share with friends and let everyone vote
📱 **Mobile-First**: Optimized for mobile browsing
🌍 **Location-Based**: Finds activities based on your area

## How It Works

1. **Create a Plan**: Enter your location and preferences
2. **Swipe on Activities**: Like or pass on suggested activities
3. **Invite Friends**: Share the link with your group
4. **Tally Votes**: See what everyone wants to do
5. **Go!**: The most popular activity wins

## Getting Started

```bash
# Install dependencies
npm install

# Start the server
npm start
```

Visit `http://localhost:3000` to start planning!

## Multi-User Testing

1. Open the app in your browser
2. Create a plan and get activities
3. Copy the share link from the "Invite Friends" section
4. Open the link in a different browser/incognito window
5. Vote on activities as a friend
6. View results to see combined votes

## Technical Features

- **Real-time Voting**: Server-side vote storage and tallying
- **Mobile Gestures**: Swipe left/right to vote on activities
- **Responsive Design**: Works on all screen sizes
- **Progressive Enhancement**: Falls back gracefully without server

## Built With

- **Frontend**: Vanilla JavaScript, CSS3, HTML5
- **Backend**: Node.js, Express
- **Styling**: Custom CSS with gradients and animations
